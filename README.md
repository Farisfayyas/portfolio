# Faris Fayyas — Portfolio

Personal portfolio website. Live at [farisfayyas.vercel.app](https://farisfayyas.vercel.app).

## Stack

Static HTML, CSS, and vanilla JavaScript. No build step.

- `index.html` — single-page layout
- `styles.css` — design system (Chakra Petch / IBM Plex Sans / JetBrains Mono, amber and cyan on dark)
- `script.js` — hero canvas animation, typed profile summary, scroll reveals

## Run locally

Serve the folder with any static server, for example:

```bash
npx serve .
```

## Deploy

Deployed on Vercel:

```bash
vercel --prod
```
